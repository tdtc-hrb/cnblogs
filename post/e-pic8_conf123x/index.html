Register Definitions: Configuration Words

PIC16(L)F18857/77
Aug 8, 2026

Legend:

  • R: Readable bit
  • P: Programmable bit
  • U: Unimplemented bit, read as ‘1’
  • ‘0’: Bit is cleared
  • ‘1’: Bit is set
  • n: Value when blank or after Bulk Erase
